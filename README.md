# open(space)

**Среда, в которой человек собирает команду ИИ-агентов, задаёт ей способ работы и копит общий
контекст задачи.**

Не «чат с несколькими моделями». Открываешь пространство под задачу, зовёшь туда нужные умы,
определяешь, как именно они должны работать вместе, — и то, до чего они додумались, остаётся
в пространстве.

```
open(product_strategy)
open(book)
open(launch)
open(brand)
open(career)
```

Название — одновременно бренд, интерфейс и команда. Open space — общая комната, где
разговаривают. Outer space — пустота и ощущение простора. `open(space)` — вызов функции:
открыть пространство. Поэтому логотип показывает текущее состояние продукта: слева режим
работы, в скобках — тема.

---

## Зачем

Главная гипотеза — не «людям нравится разговаривать с несколькими ИИ». Она сильнее:

> Команда специализированных интеллектов, работающая в явно заданном процессе и в общей
> накопленной модели задачи, позволяет решать сложные задачи лучше, чем разговор с одним
> универсальным ИИ.

Внутри три отдельные ставки, и их стоит проверять по отдельности:

| Ставка | Против чего |
|---|---|
| Team > Agent | один универсальный помощник |
| Process > Free chat | свободная переписка |
| Persistent Space > Disposable conversation | одноразовый тред |

## Для кого

Для того, кто думает работой: продукт, стратегия, текст, разбор решения. Всё работает локально,
на своей машине и на своих подписках — ключи и оплата по токенам не нужны, движки запускаются
теми же CLI, которыми пользуешься сам.

## Главный риск

**Multi-agent theatre** — пять голосов, которые вежливо соглашаются друг с другом. Выглядит
умно, стоит дорого, не добавляет ничего к одному хорошему запросу.

Поэтому ценность берётся не из количества говорящих, а из устройства мышления:

```
независимое исследование
        ↓
разная информация
        ↓
настоящее расхождение
        ↓
атака на аргументы
        ↓
синтез
        ↓
решение человека
        ↓
commit
```

Ключевая механика — **независимое исследование**. Если агенты сразу читают ответы друг друга,
первый ответ становится якорем, и пять интеллектов быстро превращаются в пять способов
согласиться с первым. Поэтому у шага режима есть `hear: нет` — участники отвечают вслепую,
читая ленту до одной и той же отметки.

## Модель

```
Space     = где            Agent   = кто
Skill     = что умеет      Context  = что знает
Mode      = как работаем   Rule     = что нельзя
Memory    = что усвоили
```

Что из этого уже есть:

| | Состояние |
|---|---|
| **Space** | одна машина, комнаты по `?room=` |
| **Agent** | есть: ник, роль, характер, движок, модель, уровень доступа, аватарка |
| **Mode** | есть: 15 режимов, редактор режимов в настройках |
| **Rule** | частично: правила свободного разговора, «без кого режим не работает» |
| **Context** | частично: общая цель разговора |
| **Memory** | написана, не подключена (`lib/memory.js`) |
| **Skill** | нет |

Подробно и с планом — [docs/concept.md](docs/concept.md).

## Запуск

```bash
node server.js
```

Открыть `http://localhost:4477`. Порт, папку и ник можно переопределить:

```bash
node server.js --port 4477 --workdir ../my-project --human roman
```

Клиент собирается отдельно (сборка в `public/` не коммитится):

```bash
cd web && npm install && npm run build
```

Нужны установленные и залогиненные `claude` и `codex` — движки запускаются как обычные CLI.

## Как это работает

Никто не крутится в цикле и не сторожит файл. Участника будит обращение:

```
человек пишет «@эстет ...»
        ↓
  сервер будит движок этого участника  →  ответ в ленту  →  в ответе есть «@инженер»
                                                                    ↓
                                                          сервер будит @инженер  → ...
```

Каждый получает только то, что появилось с его прошлого хода, а не весь тред заново.

Устройство, движки, уровни доступа, экономия, API — [docs/architecture.md](docs/architecture.md).

## Правила разговора

- **Тег адресует реплику.** Написал `@скептик` — отвечает он.
- **Без тега отвечают дежурные** — по очереди, каждый видит предыдущих. Кто дежурит,
  настраивается в режиме «Открытый».
- **Агент без тега продолжает с предыдущим собеседником** — будится ровно один, эхо
  не расходится.
- **`[skip]`** — законный ход: сказать нечего, ленту не засоряем.
- **Стоп-кран.** После N реплик подряд без человека разговор сам встаёт на паузу.
- **Esc** — пауза. Кто уже пишет — договорит: ответ оплачен, терять его незачем.

## Настройка

Всё правится в интерфейсе, профиль в шапке → Настройки. Применяется сразу, перезапуск не нужен.

- **Участники** — кто здесь: ник, роль, что делает, как говорит, движок, модель, доступ.
- **Режимы** — как работаем: шаги, кто говорит на шаге, слышат ли друг друга, чем шаг
  закрывается. Редактор пишет те же файлы `modes/*.md`.
- **Пространство** — зачем мы здесь, память участников, лента.

Файл `openspace.config.json` — то же самое на диске.
