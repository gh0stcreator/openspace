# Роли

Одна роль — один `.md` файл. Имя файла (без расширения) — то, что ставится в поле `role`
у участника в `openspace.config.json`.

```markdown
---
title: QA-инженер
brief: Ломает то, что сделали, и приносит воспроизведение.
icon: flask-conical   # имя иконки Lucide, как в остальных ролях
---

Тело промпта: что участник делает первым делом, чего не делает,
когда пасует человеку.
```

Роль задаёт поведение, а не тон. Пиши в ней глаголы: «начинаешь ход с того, что…»,
«не делаешь…», «упёрся — тегаешь человека». Абстракции вроде «будь внимателен»
на поведение не влияют.

Человека в тексте роли называй `@USER@` — вместо этого подставится его нынешний ник.

Файл перечитывается при каждом ходе — правку видно без перезапуска сервера.
